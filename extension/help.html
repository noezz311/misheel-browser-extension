Сонгоод, утгыг нь хараарай.

Мишээл аппын солонгос–монгол толь одоо таны browser-т.

  1. Вэб хуудас нээнэ.

    Extension суулгахын өмнө нээсэн хуудас байвал нэг удаа refresh хийнэ.

  2. Солонгос үг эсвэл хэллэг сонгоно.

    Хулганаар чирэх эсвэл үгэн дээр хоёр дарна. Монгол утга нь сонгосон текстийн хажууд гарна.

  3. Үгээ уншаад үргэлжлүүлнэ.

    Гадна талд дарах, × товч эсвэл Esc дарж хаана. Browser-ийн toolbar дахь Мишээл дүрсээр шууд хайж, автоматаар гаргахыг унтрааж болно.

Офлайн толь

Таны өгсөн Android аппын толь дээр үндэслэсэн. API key, бүртгэл, интернет шаардлагагүй. Сонгосон текстийг сервер рүү илгээхгүй.

Үг болон тольд байгаа хэллэгийн утгыг харуулна. Бүтэн өгүүлбэр сонговол олдсон үгсийн утгыг тус тусад нь харуулна. Нөхцөлтэй үгсийг зарим үндсэн хэлбэрээр хайна; солонгос хэлний бүх хувирлыг танихгүй.

«Google Translate-аар өгүүлбэр орчуулах» холбоосыг өөрөө дарвал сонгосон текст Google Translate дээр нээгдэнэ.

PDF нээгээд текстээ сонгоорой

PDF-ээ Chrome / Edge-ээр нээгээд солонгос текстээ сонгоход л утга нь гарна. Мишээл нь вэб PDF болон зөвшөөрөлтэй дотоод PDF-ийг тухайн tab-д өөрийн уншигчаар автоматаар нээнэ. Баруун товчийн цэс ашиглах, файлаа дахин сонгох шаардлагагүй. Уншигч анх «Унших» горимд байна.

Компьютерийн PDF-д extension тохиргооны Details → Allow access to file URLs-ийг нэг удаа асаана. Toolbar-ийн popup дахь «PDF-ийг автоматаар нээх» тохиргоо анхнаасаа асаалттай. Унтраавал browser-ийн ердийн PDF viewer-д нээгдэнэ. Толийн цонх нь Мишээлийн уншигчид ажиллана.

Гараар нээх бол toolbar дахь «PDF файл нээх» → уншигчийн «PDF файл сонгох» товчийг ашиглана. Эсвэл PDF-ээ чирж оруулна; 200 МБ хүртэл файл нээнэ. Файл сонгох арга нь интернет болон нэмэлт файлд хандах зөвшөөрөл шаардахгүй. Нээлттэй PDF-д «Энэ PDF-ийг Мишээлээр нээх» товчийг мөн ашиглаж болно. Холбоосоор нээгдэхгүй бол PDF-ээ татаж аваад файл сонгох товчоор нээнэ.

PDF-ийн хуудсуудыг доош тасралтгүй гүйлгэж уншина. Гүйлгэхэд хуудасны дугаар автоматаар шинэчлэгдэнэ. PDF нээх, хуудас солих, хуудасны дугаар оруулах, томруулах/жижигрүүлэх, өргөнд тааруулах, тэмдэглэгээ хийх болон PDF хадгалах удирдлагууд баруун талын самбарын дээд хэсэгт байна. Солонгос үгээ сонгоход монгол утга удирдлагуудын доорх толийн хэсэгт гарна. Жижиг дэлгэц дээр удирдлага болон толь PDF-ийн доор байрлана.

Толийн цонх сонгож болдог тексттэй PDF дээр ажиллана. Сканнердсан зураг хэлбэрийн PDF-д OCR ороогүй.

PDF тэмдэглэгээ болон хадгалах

Баруун талын самбарын тэмдэглэгээний хэрэгслүүдээр Edge-ийн PDF хэрэгслүүдтэй адил хуудас дээр тэмдэглэгээ хийж болно:

  • Тодруулах: текстээ чирж сонгоод өнгөөр тодруулна.
  • Зурах: хулгана эсвэл үзгээр зурна. Өнгө болон үзгийн өргөнийг сонгоно.
  • Текст нэмэх: хуудас дээр дарж тэмдэглэл бичнэ. Өнгө болон текстийн хэмжээг сонгоно.
  • ↶ / ↷: тэмдэглэгээний үйлдлийг буцаах / дахин хийх. Устгах: сонгосон тэмдэглэгээг устгана.

Тэмдэглэгээний горимд толийн цонх гарахгүй. Үгийн утга харахдаа «Унших» руу буцна. Текст нэмэх нь шинэ тэмдэглэл тавих хэрэгсэл; эх PDF-ийн үндсэн өгүүлбэрийг сольж засахгүй.

«PDF хадгалах» товчоор эх-файлын-нэр-misheel.pdf нэртэй шинэ хуулбар татна. Тодруулга, зураг, текстийг стандарт PDF тэмдэглэгээгээр хадгалдаг тул Мишээл, Edge болон бусад PDF уншигчаар дахин нээж харж болно. Файлаа хаахаас өмнө өөрчлөлтөө хадгалаарай.

Нууц үгтэй PDF-д монгол, солонгос текстэн тэмдэглэл хадгалахад нууц үггүй PDF хувилбар шаардлагатай байж болно. Хадгалахад алдаа гарвал өөрчлөлт одоо нээлттэй уншигчид хэвээр байна.

Дотоод PDF унших, тэмдэглэх, хадгалах болон толь офлайнаар ажиллана; файлыг серверт байршуулахгүй. Вэб PDF нээхэд эх сайтаас файлыг татна.

Компьютерт хадгалсан HTML файл

Browser-ийн extension тохиргооноос Мишээлийг сонгоод Details → Allow access to file URLs-ийг асаана. Дараа нь browser-т нээсэн HTML файл эсвэл хадгалсан вэб хуудсаа refresh хийгээд солонгос текст сонгоно.

Энэ тохиргоог асаавал browser-т нээлттэй локал PDF-ийг Мишээл уншигчид шууд нээхэд мөн ашиглана. PDF уншигчийн файл сонгох товчоор нээхэд энэ тохиргоо шаардлагагүй.

Хаана ажиллах вэ?

Chrome 125 болон түүнээс шинэ Chrome/Edge дээр, ердийн HTTP/HTTPS хуудас, зөвшөөрсөн локал HTML файл, Мишээл PDF уншигчид ажиллана. Browser-ийн тохиргоо, extension store, шинэ tab, бичиж буй input, textarea болон засварлах талбарууд дээр автоматаар гаргахгүй.

Утга харагдахгүй бол хуудсаа refresh хийгээд, Мишээл дүрсээр хайлт хийж үзээрэй. Хайлтаар олдохгүй байвал тухайн үг тольд байхгүй эсвэл үндсэн хэлбэрээр хайх хэрэгтэй байж болно.
