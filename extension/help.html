Сонгоод, утгыг нь хараарай.

Мишээл аппын солонгос–монгол толь одоо таны browser-т.

  1. Вэб хуудас нээнэ.

    Extension суулгахын өмнө нээсэн хуудас байвал нэг удаа refresh хийнэ.

  2. Солонгос үг эсвэл хэллэг сонгоно.

    Хулганаар чирэх эсвэл үгэн дээр хоёр дарна. Монгол утга нь сонгосон текстийн хажууд гарна.

  3. Үгээ уншаад үргэлжлүүлнэ.

    Гадна талд дарах, × товч эсвэл Esc дарж хаана. Browser-ийн toolbar дахь Мишээл дүрсээр шууд хайж, автоматаар гаргахыг унтрааж болно.

Офлайн толь

Таны өгсөн Android аппын толь дээр үндэслэсэн. API key, бүртгэл, интернет шаардлагагүй. Сонгосон текстийг сервер рүү илгээхгүй.

Үг болон тольд байгаа хэллэгийн утгыг харуулна. Бүтэн өгүүлбэр сонговол олдсон үгсийн утгыг тус тусад нь харуулна. Нөхцөлтэй үгсийг зарим үндсэн хэлбэрээр хайна; солонгос хэлний бүх хувирлыг танихгүй.

«Google Translate-аар өгүүлбэр орчуулах» холбоосыг өөрөө дарвал сонгосон текст Google Translate дээр нээгдэнэ.

PDF дээр ашиглах

Toolbar дахь Мишээл дүрсийг дараад «PDF файл нээх» сонгоно. Уншигч дээр PDF файлаа сонгох эсвэл чирж оруулаад, солонгос үгээ сонгоорой. Утга нь хажууд нь гарна. Хуудас солих, хуудасны дугаар оруулах, томруулах болон дэлгэцийн өргөнд тааруулах боломжтой.

Browser-т PDF нээлттэй байвал «Энэ PDF-ийг Мишээлээр нээх» товч харагдана. Файл руу нэвтрэх эрхгүй бол PDF-ээ татаж аваад уншигчийн файл сонгох товчоор нээнэ. Файл сонгох арга нь интернет болон нэмэлт файлд хандах зөвшөөрөл шаардахгүй.

Текст нь зураг хэлбэрээр хадгалсан скан PDF-д OCR хэрэгтэй. Энэ хувилбарт OCR ороогүй; сонгож болдог тексттэй PDF дээр орчуулна. Chrome/Edge-ийн өөрийн PDF viewer дотор шууд цонх гаргах боломжгүй тул PDF-ээ Мишээл уншигчаар нээнэ.

Компьютерт хадгалсан HTML файл

Browser-ийн extension тохиргооноос Мишээлийг сонгоод Details → Allow access to file URLs-ийг асаана. Дараа нь browser-т нээсэн HTML файл эсвэл хадгалсан вэб хуудсаа refresh хийгээд солонгос текст сонгоно.

Энэ тохиргоог асаавал browser-т нээлттэй локал PDF-ийг Мишээл уншигчид шууд нээхэд мөн ашиглана. PDF уншигчийн файл сонгох товчоор нээхэд энэ тохиргоо шаардлагагүй.

Хаана ажиллах вэ?

Chrome 125 болон түүнээс шинэ Chrome/Edge дээр, ердийн HTTP/HTTPS хуудас, зөвшөөрсөн локал HTML файл, Мишээл PDF уншигчид ажиллана. Browser-ийн тохиргоо, extension store, шинэ tab, бичиж буй input, textarea болон засварлах талбарууд дээр автоматаар гаргахгүй.

Утга харагдахгүй бол хуудсаа refresh хийгээд, Мишээл дүрсээр хайлт хийж үзээрэй. Хайлтаар олдохгүй байвал тухайн үг тольд байхгүй эсвэл үндсэн хэлбэрээр хайх хэрэгтэй байж болно.
