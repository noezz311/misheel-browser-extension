# Мишээл · Misheel

**Солонгос текст сонгоод монгол утгыг нь хажууд нь хараарай.** Chrome / Edge-д зориулсан офлайн толь: вэб хуудас, дотоод HTML файл болон browser-т нээсэн PDF дээр ажиллана. PDF нь Мишээлийн уншигчид автоматаар нээгдэж, үгээ сонгоход л утга нь гарна. PDF дээр тодруулах, зурах, текст нэмэх, тэмдэглэгээтэй хуулбар хадгалах боломжтой.

**한국어 텍스트를 선택하면 바로 옆에 몽골어 뜻이 표시됩니다.** Chrome / Edge용 오프라인 사전입니다. PDF를 브라우저에서 열면 Misheel 리더로 자동 전환되어 선택만으로 뜻을 확인하고, 형광펜·펜·텍스트 주석을 추가한 PDF를 저장할 수 있습니다.

## Суулгах

Chrome 125+ эсвэл түүнтэй дүйцэх Chromium суурьтай Edge ашиглана. Extension суулгахад Node.js, Python, API key эсвэл бүртгэл хэрэггүй. Дараах хоёр аргын аль нэгээр файлуудаа **байнгын хадгалах хавтас руу** татаж задлана.

- **Бэлэн багц:** [misheel-extension.zip](misheel-extension.zip)-ийг татаж задлана. Задалсан хавтас дотор `manifest.json` байна.
- **Репозиторын файлууд:** GitHub-ийн **Code → Download ZIP**-ийг сонгоод задлана. Extension нь задлагдсан төслийн **`extension/`** хавтсанд байна. Репозиторийг clone хийсэн бол мөн энэ хавтсыг ашиглана.

Дараа нь:

1. Chrome-ийн хаягийн мөрөнд `chrome://extensions`, эсвэл Edge дээр `edge://extensions` гэж бичиж нээнэ.
2. **Developer mode / Хөгжүүлэгчийн горим**-ыг асаана.
3. **Load unpacked / Задалсан өргөтгөл ачаалах** товчийг дарна.
4. **`manifest.json` байгаа хавтсыг** сонгоно. Репозиторын ZIP ашигласан бол `extension/`; бэлэн ZIP ашигласан бол түүнийг задласан хавтас.
5. Өмнө нээсэн вэб хуудсаа **Refresh** хийнэ. Browser-ийн өргөтгөлийн цэснээс Мишээлийг toolbar дээр pin хийвэл шууд хайлт болон PDF уншигчид хурдан орно.

Суулгах дэлгэрэнгүйг [Chrome-ийн албан ёсны заавар](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked), [Edge-ийн албан ёсны заавар](https://learn.microsoft.com/en-us/microsoft-edge/extensions/getting-started/extension-sideloading)-аас харж болно.

## Вэб дээр ашиглах

1. Солонгос үг эсвэл богино хэллэгийг хулганаар чирж сонгоно. Үгэн дээр хоёр дарах, гарын товчлуураар текст сонгох аргыг мөн ашиглаж болно.
2. Сонголтын хажууд монгол утга, байгаа бол дуудлага болон солонгос–монгол тайлбарууд гарна.
3. **Esc**, **×** эсвэл цонхны гадна талд дарж хаана.

Toolbar-ийн **Мишээл** дүрсээр үгээ гараар хайж, текст сонгоход автоматаар гаргахыг асааж/унтрааж болно. `학교`, `사과`, `한국어` зэрэг үгээр туршаарай. Extension-ийн интерфейс монгол хэлтэй.

## Дотоод HTML болон PDF файл

### HTML файл

Компьютерт хадгалсан `.html` файлаа Chrome эсвэл Edge-ээр нээж, вэб хуудасны адил текстээ сонгоно. `file://` хуудсанд extension ажиллуулахын тулд:

1. `chrome://extensions` эсвэл `edge://extensions` дээр Мишээлийн **Details / Дэлгэрэнгүй** хэсгийг нээнэ.
2. **Allow access to file URLs / Файлын URL-д хандахыг зөвшөөрөх** тохиргоог асаана.
3. HTML файлын tab-аа refresh хийгээд солонгос текст сонгоно.

### PDF файл

![PDF дотор сонгосон солонгос үгийн хажууд гарч буй монгол утга](docs/images/pdf-selection.png)

**PDF-ээ browser-т нээгээд солонгос текстээ сонгоход л утга нь гарна.** Мишээл нь вэб PDF болон зөвшөөрөлтэй дотоод PDF-ийг **тухайн tab-д** өөрийн уншигчаар автоматаар нээнэ. Баруун товчийн цэс ашиглах, PDF-ээ дахин сонгох шаардлагагүй.

1. Компьютерт хадгалсан `.pdf` файлаа Chrome / Edge-ээр нээх эсвэл вэб PDF-ийн холбоосыг нээнэ. Дотоод файлыг автоматаар нээхэд Мишээлийн **Details → Allow access to file URLs** тохиргоог нэг удаа асаана.
2. Мишээлийн уншигч автоматаар нээгдэнэ. **Унших** горим анхнаасаа сонгогдсон байна.
3. Солонгос үг, хэллэгээ хулганаар сонгоно. Монгол утга нь **баруун талын толийн хэсэгт** гарна. PDF-ийн хуудсуудыг хулганын хүрд эсвэл trackpad-аар **доош тасралтгүй гүйлгэж** уншина. Хуудасны дугаар гүйлгэх үед автоматаар шинэчлэгдэнэ.

PDF нээх, хуудас солих, томруулах/жижигрүүлэх, өргөнд тааруулах, тэмдэглэгээ хийх болон PDF хадгалах удирдлагууд **баруун талын самбарын дээд хэсэгт** байна. Монгол утга нь **удирдлагуудын доорх толийн хэсэгт** гарна. Жижиг дэлгэц дээр удирдлага болон толь PDF-ийн доор байрлана.

Toolbar-ийн popup дахь **PDF-ийг автоматаар нээх** тохиргоо анхнаасаа асаалттай. Унтраавал PDF нь browser-ийн ердийн PDF viewer-д нээгдэнэ. Browser-ийн өөрийн viewer-д толийн цонх нэмэхийн оронд Мишээл нь PDF-ийг өөрийн уншигчид нээж, сонголтын орчуулга болон тэмдэглэгээг ажиллуулдаг. Вэб PDF-ийн үндсэн tab-ийг танина; HTML хуудсан доторх PDF iframe нь бүх хуудсыг уншигч руу шилжүүлэхгүй.

Гараар нээх бол popup-ийн **PDF файл нээх** → уншигчийн **PDF файл сонгох** товчийг ашиглана. Файлаа уншигч руу чирж оруулж болно; 200 МБ хүртэл файл нээнэ. Энэ аргаар **Allow access to file URLs** тохиргоо шаардлагагүй. Одоо нээлттэй PDF-д popup-ийн **Энэ PDF-ийг Мишээлээр нээх** товчийг мөн ашиглаж болно. Зөвшөөрөл, нэвтрэлт эсвэл redirect-ийн улмаас холбоосоор нээгдэхгүй бол PDF-ээ татаж аваад файл сонгох товчоор нээнэ.

### PDF дээр тэмдэглэгээ хийх, хадгалах

![Мишээлийн PDF уншигчийн тодруулга, зураг, текстэн тэмдэглэл болон хадгалах хэрэгслүүд](docs/images/pdf-annotations.png)

Edge-ийн PDF хэрэгслүүдтэй адил тодруулах, үзгээр зурах, текстэн тэмдэглэл нэмэх боломжтой. Баруун талын самбарын тэмдэглэгээний хэрэгслүүдээс горимоо сонгоно:

| Хэрэгсэл | Хийх үйлдэл |
| --- | --- |
| **Унших** | Солонгос текстээ сонгож монгол утгыг харах |
| **Тодруулах** | Текстээ чирж сонгоод өнгөөр тодруулах |
| **Зурах** | Хулгана эсвэл үзгээр хуудас дээр зурах; өнгө, үзгийн өргөнийг сонгох |
| **Текст нэмэх** | Хуудас дээр дарж тэмдэглэл бичих; өнгө, текстийн хэмжээг сонгох |
| **↶ / ↷** | Тэмдэглэгээний үйлдлийг буцаах / дахин хийх |
| **Устгах** | Сонгосон тэмдэглэгээг устгах |
| **PDF хадгалах** | Тэмдэглэгээтэй PDF хуулбарыг татах |

**Alt + T** товчоор **Текст нэмэх ↔ Унших** горимыг ээлжлэн солино. Тэмдэглэл бичиж байхдаа горим сольсон ч бичсэн текст хэвээр үлдэнэ.

Тэмдэглэгээний горимд толийн цонх гарахгүй. Үгийн утга харахдаа **Унших** руу буцна. Текст нэмэх нь хуудсан дээр шинэ тэмдэглэл тавина; эх PDF-ийн үндсэн өгүүлбэрийг сольж засах хэрэгсэл биш.

**PDF хадгалах** нь `эх-файлын-нэр-misheel.pdf` нэртэй шинэ PDF татна. Тодруулга, зураг, текстэн тэмдэглэлийг стандарт PDF тэмдэглэгээгээр хадгалдаг тул хадгалсан файлыг Мишээл, Edge болон бусад PDF уншигчаар дахин нээж харж болно. Файлаа хаахаас өмнө өөрчлөлтөө хадгалаарай.

Нууц үгтэй PDF-д монгол, солонгос текстэн тэмдэглэл хадгалахад нууц үггүй PDF хувилбар шаардлагатай байж болно. Хадгалахад алдаа гарвал өөрчлөлт одоо нээлттэй уншигчид хэвээр байна.

Дотоод PDF унших, тэмдэглэх, хадгалах болон толь офлайнаар ажиллана. PDF-ийг серверт байршуулахгүй. Вэб PDF нээхэд тухайн PDF-ийн эх сайтаас файлыг татна. **Текст сонгогддог PDF** дээр толийн цонх ажиллана; сканнердсан зураг хэлбэрийн PDF-д OCR ороогүй.

## Толийн өгөгдөл

Мишээл Android APK-ийн офлайн толийг ашигласан. Багцад дараах өгөгдөл орсон:

| Өгөгдөл | Тоо |
| --- | ---: |
| Үгийн бичлэг | 51,794 |
| Үгийн утга | 71,500 |
| Хэлц | 2,225 |
| Зүйр үг | 652 |
| Хэлц, зүйр үгийн утга ба тайлбар | 3,190 |
| Нийт үг, хэлц, зүйр үгийн бичлэг | 54,671 |

Үгийн бичлэгт ижил бичлэгтэй өөр утгууд ордог. Дэлгэрэнгүй тоо, эх өгөгдлийн hash болон экспортын тэмдэглэлийг [extension/data/index.json](extension/data/index.json)-аас харж болно.

Үр дүнгийн доорх солонгос–монгол хэсгүүд нь **утгын тайлбар**, орчуулсан хэрэглээний жишээ өгүүлбэр биш. Эх өгөгдлийн 1,684 бичлэгийн товч монгол утга хоосон; тэдгээрт байгаа бусад тайлбарыг хадгалсан. Монгол орчуулгагүй 4,479 хэрэглээний өгүүлбэрийг экспортод оруулаагүй.

## Хайлтын хүрээ, нууцлал

- Үг, тольд байгаа хэллэг, хэлц, зүйр үгийг эхлээд яг тааруулж хайна. Бүтэн хэллэг олдохгүй бол дотор нь байгаа солонгос үгсийн утгыг тус тусад нь харуулна.
- Зарим нөхцөл, нэр үгийн `입니다` зэрэг төгсгөл, үйл үгийн `먹었습니다`, `갑니다`, `갔어요`, `봤어요` зэрэг түгээмэл хувирлыг үндсэн хэлбэрээр хайна. Вэбийн үл харагдах форматлах тэмдэгтүүдийг хайлтын өмнө цэвэрлэнэ. Солонгос хэлний бүх хувирлыг танихгүй; олдохгүй бол үндсэн хэлбэрээр хайж үзээрэй.
- Энэ нь **бүтэн өгүүлбэрийг шинээр орчуулдаг машин орчуулга биш**. Google Translate холбоосыг өөрөө дарвал сонгосон текстийг Google Translate руу илгээж, өгүүлбэрээ тэнд орчуулж болно.
- Нэг удаагийн сонголт **500 хүртэл тэмдэгттэй** байна. Хэллэгийн хайлтад эхний 20 ялгаатай үгийг шалгаж, хамгийн ихдээ 16 толийн бичлэг харуулна. Хязгаарт хүрвэл цонхонд тэмдэглэнэ.
- Толь болон PDF уншигч офлайнаар ажиллана. Сонгосон текст, дотоод файлыг сервер рүү автоматаар илгээхгүй.
- Ердийн HTTP/HTTPS хуудас, зөвшөөрөгдсөн iframe, зөвшөөрөл өгсөн дотоод HTML болон Мишээлийн PDF уншигч дээр ажиллана. Browser-ийн тохиргоо, шинэ tab, extension store, өөрийн PDF viewer болон input/textarea зэрэг бичих талбарт сонголтын цонх гарахгүй.

## Хөгжүүлэлт, өгөгдөл дахин гаргах

Өдөр тутам ашиглахад хөгжүүлэлтийн хэрэгсэл шаардлагагүй. Шалгалтад Node.js, browser-ийн шалгалтад Playwright болон Chromium/Chrome, ZIP багцлахад PowerShell ашиглана.

```powershell
# Толийн логик болон экспортлогдсон өгөгдлийг шалгах
npm test

# Browser-ийн шалгалтын хэрэгслийг суулгаж ажиллуулах
npm install --no-save playwright
npx playwright install chromium
npm run test:browser
npm run test:pdf
npm run test:automatic
npm run test:annotations
npm run test:sidebar

# Windows / PowerShell: extension багцыг дахин үүсгэх
npm run package
```

`PLAYWRIGHT_MODULE` болон `BROWSER_EXECUTABLE` орчны хувьсагчаар өөр Playwright эсвэл browser-ийн байршлыг зааж болно. Шалгалтын тайлан, зураг `artifacts/` дотор үүснэ.

Эх Android **APK репозиторт ороогүй**. Багцын толийн өгөгдөл бэлэн орсон тул суулгахын өмнө exporter ажиллуулах хэрэггүй. Өгөгдлийг дахин гаргах бол Python 3 болон тохирох APK файлаа ашиглана:

```powershell
python tools/export_dictionary.py --apk "C:\path\to\misheel.apk"
npm test
npm run package
```

Exporter нь энэ APK-ийн `assets/realm/default.realm`, Realm file format 20 болон schema-д зориулагдсан; өөр APK хувилбарт тохирох эсэхийг тусад нь шалгана. Эх APK-г өөрчлөхгүй. `tools/make-icons.py`-г дахин ажиллуулахад Pillow болон Windows-ийн Malgun Gothic фонт хэрэгтэй; бэлэн icon файлууд extension-д орсон.

Extension-ийн код эсвэл өгөгдлийг өөрчилсний дараа Extensions хуудсан дээр **Reload** хийж, ашиглах вэб хуудсаа мөн refresh хийнэ.
